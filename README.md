# Web Programming Project
A first year project to create a website portfolio with responsive design techniques using HTML5 and CSS.
Basic Multi-page structure (e.g Home, About, Portfolio and Contact Page) Followed.
HTML5 semantic elements implemented (<header>, <nav>, <main>, <section>,<footer>).
CSS used to style the pages, typography, color schemes and layout.
Consistent navigation menu followed across all pages.
This is a static, non-responsive website with a consistent design across all pages
